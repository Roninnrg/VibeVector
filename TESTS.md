## Ключевые сценарии

**Загрузка → ready (E2E).** Тест создаёт WAV-файл, отправляет его через
`POST /api/lectures/upload`, дожидается завершения фоновой задачи и проверяет,
что лекция получила статус `ready`, непустую расшифровку, главы, конспект и
векторы. Это тот же путь, которым идёт реальный пользователь.

**Семантика без точных слов.** Запрос «как учится нейросеть» находит фрагмент
«Так сеть постепенно уменьшает ошибку и учится на данных»: слова «нейросеть» в
тексте нет, но dense-близость и леммы дают правильный результат.

**Клик по реплике = перемотка.** API отдаёт таймкоды каждой реплики, а тесты
проверяют корректность `start`/`end`, deep-link `?t=` и формат субтитров.

**Экспорт.** Markdown содержит конспект, тезисы, главы и расшифровку;
`Content-Disposition` корректно кодирует кириллическое имя файла
(`filename*=UTF-8''…`). VTT и SRT проходят проверку заголовков и разметки.

**Безопасность и устойчивость.** Проверяются защитные заголовки, отказ от
path traversal в SPA fallback, лимит размера файла, неподдерживаемые форматы,
некорректные ссылки, удаление во время обработки (409), пустые файлы.

**Аккаунты и избранное.** Регистрация создаёт пользователя и HTTP-only сессию;
повторный email и неверный пароль дают понятные ошибки. Избранное доступно
только после входа, переключается идемпотентно, отражается в карточке лекции
и профиле, а при удалении лекции очищается каскадом. Смена пароля завершает
остальные сеансы. Факты отдаются публично и не повторяются при `exclude`.

## Изоляция тестов

`tests/conftest.py`:

- общая временная SQLite-база на всю сессию, очистка таблиц перед каждым тестом,
  без записи в `data/`; таблицы аккаунтов и избранного очищаются вместе с лекциями;
- `HashingEmbedder` и `MockASR` — быстрые, детерминированные, без сети;
- фикстура `insert_lecture()` создаёт лекцию с репликами, главами и векторами;
- `make_wav()` генерирует валидный WAV без ffmpeg;
- `TestClient` поднимает приложение в том же процессе, фоновые задачи
  дожидаются завершения.

## Реальный ASR

Дымовой прогон настоящего `faster-whisper` (модель должна быть скачана,
занимает ~15–40 секунд на CPU):

```powershell
$env:VECTOR_SLOW_TESTS="1"
python -m pytest tests/test_asr.py -q
```

```bash
VECTOR_SLOW_TESTS=1 python -m pytest tests/test_asr.py -q
```

Тест синтезирует короткий WAV, распознаёт его и проверяет, что получен
непустой текст с валидными таймкодами.

## Ошибки, найденные тестами

Тесты поймали четыре реальных дефекта, которые исправлены в коде:

1. **Экспорт с кириллическим названием** ломал заголовок `Content-Disposition`
   сырыми не-ASCII байтами — теперь имя кодируется через `quote()`.
2. **Нарезка предложений** считала висячим союзом любое слово на «и»
   («геометрии», «информации») — исправлено условие для односложных союзов.
3. **Склейка слов Whisper** вставляла пробел перед знаками препинания —
   теперь пунктуация приклеивается к предыдущему слову.
4. **Подсветка сниппетов** не находила словоформы («угол» → «углы») — теперь
   подсветка работает по леммам и не ломает HTML.

## Ограничения тестов

- UI-тесты не автоматизированы в pytest: SPA проверяется браузерным
  smoke-прогоном вручную (консоль, мобильная вёрстка, плеер).
- Тесты не измеряют качество ASR на реальных лекциях: для этого нужен
  размеченный датасет.
- Нагрузочное тестирование не проводилось; прототип рассчитан на локальный
  запуск и одну очередь обработки.
