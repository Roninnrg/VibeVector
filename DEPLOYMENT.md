# Деплой «Вектора» на GitHub Codespaces

## Публичный адрес

**https://vector-demo-r746jqgxr5hpj54-8000.app.github.dev**

Репозиторий: **https://github.com/Roninnrg/VibeVector**

Демо запущено в GitHub Codespaces (бесплатный тариф аккаунта): 2 vCPU, 8 ГБ RAM,
32 ГБ диска. При первом открытии ссылки GitHub один раз показывает
предупреждение «You are about to access a development port…» — нажмите
**Continue**. Дальше сайт открывается как обычный HTTPS-сайт.

## Ограничения демо

- Codespace **останавливается после 4 часов бездействия**. Ссылка перестаёт
  отвечать, пока Codespace не запустят снова. Диск и данные сохраняются.
- Codespace **удаляется через 7 дней** после остановки (retention period).
  Это демонстрационный стенд, а не постоянный хостинг.
- Импорт по ссылке: **VK Видео, Rutube, Dailymotion и прямые MP4/WebM**
  работают с IP Codespace и проверены до статуса `ready`. **YouTube и Vimeo**
  блокируют IP дата-центра («Sign in to confirm you're not a bot» / «The web
  client only works when logged-in»). Это ограничение платформ: обойти его
  сменой клиента yt-dlp нельзя. Варианты — загрузка файла, cookies через
  `YTDLP_COOKIES_FILE`/`YTDLP_COOKIES_B64` или прокси с обычным IP.
- На 2 vCPU распознавание идёт медленнее, чем локально; демо-лекции уже
  проиндексированы, поэтому поиск и Q&A отвечают мгновенно.
- Загруженные пользователем файлы живут на диске Codespace и исчезнут вместе
  с ним.

## Перезапуск после остановки

```bash
gh codespace start -c vector-demo-r746jqgxr5hpj54
gh codespace ssh -c vector-demo-r746jqgxr5hpj54 -- \
  "cd /workspaces/VibeVector && bash scripts/start_codespace.sh"
gh codespace ports visibility 8000:public -c vector-demo-r746jqgxr5hpj54
```

Скрипт `scripts/start_codespace.sh` идемпотентен: при необходимости создаёт
окружение, ставит ffmpeg, скачивает модели, засевает демо-данные и запускает
сервер. В `devcontainer.json` он назначен на `postStartCommand`, поэтому при
пересоздании Codespace сервер поднимется автоматически.
