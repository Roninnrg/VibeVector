КАК ЗАПУСТИТЬ ПРОЕКТ "ВЕКТОР"

1. УСТАНОВКА (только первый раз)
   - Распакуйте папку с проектом в любое место (например, на Рабочий стол)
   - Дважды кликните УСТАНОВКА.bat
   - Дождитесь окончания (10-20 минут). Будет скачано ~1.5 ГБ
   - По окончании появится надпись "УСТАНОВКА ЗАВЕРШЕНА!"

2. ЗАПУСК (каждый раз)
   - Дважды кликните START.bat
   - Автоматически откроется браузер по адресу http://127.0.0.1:8000
   - Для остановки сервера закройте окно START.bat или нажмите Ctrl+C

ТРЕБОВАНИЯ
- Windows 10/11
- Python 3.10+ (скачать с https://www.python.org/downloads/)
- ~4 ГБ свободного места на диске
- Интернет при первой установке

ВАЖНО
- При установке Python ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"
- Не закрывайте окна .bat файлов во время работы
- Если порт 8000 занят, закройте другие программы или измените порт

ПРОБЛЕМЫ
- Если Windows блокирует запуск .bat - нажмите "Подробнее" -> "Выполнить в любом случае"
- Если не открывается браузер - вручную откройте http://127.0.0.1:8000
- Если нет интернета при установке - модели уже есть в проекте, можно пропустить скачивание

ВСЁ ГОТОВО!
