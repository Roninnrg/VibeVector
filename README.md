# Вектор

**Найдите момент, а не таймкод.** «Вектор» — прототип семантического поиска по
видеолекциям: загрузите запись или ссылку, получите расшифровку с таймкодами,
конспект, главы, термины и поиск по смыслу — с мгновенным переходом к нужной
секунде.

Проект сделан для хакатона «Киберрывок · Осень 2026» и полностью работает
локально: распознавание речи, эмбеддинги и поиск не требуют интернета после
первичной загрузки моделей.

```
Загрузите лекцию → «Вектор» расшифрует, структурирует и проиндексирует её
→ спросите «почему теорема верна?» → плеер откроется на 1:06
```

## Что умеет

| Возможность | Как это работает |
|---|---|
| **Загрузка видео** | Drag & drop MP4 / WebM / MOV / MKV, аудио MP3 / M4A / WAV. Уникальный ID, безопасное имя файла, лимит размера, проверка через `ffprobe`. |
| **Импорт по ссылке** | YouTube и Vimeo через `yt-dlp`, прогресс в общей очереди. |
| **Транскрибация** | `faster-whisper` (CTranslate2, int8, CPU), автоопределение языка, таймкоды до секунды и word-level timestamps. |
| **Семантический индекс** | `model2vec` potion-multilingual-128M, 101 язык, float32-векторы в SQLite. Есть офлайн-резерв на хешах, если модель не скачана. |
| **Поиск по смыслу** | Гибрид: dense cosine + BM25 по леммам + покрытие запроса + фразовый бонус, диверсификация MMR. Работает по одной лекции и по всему курсу. |
| **Плеер** | Собственный плеер: play/pause, ±10 с, скорость, звук, fullscreen, синхронные субтитры, клик по реплике — перемотка, deep link `?t=123`. |
| **Конспект и структура** | Экстрактивный конспект TextRank, ключевые тезисы с таймкодами, автоматические главы, термины с первым упоминанием. |
| **Вопрос-ответ** | RAG по лекции: ответ с цитатами и таймкодами. Офлайн — экстрактивный режим, опционально — любой OpenAI-совместимый LLM. |
| **Экспорт** | Конспект + главы + полная расшифровка в Markdown, субтитры VTT/SRT. |
| **Диагностика** | `/api/health`, статистика, история запросов, проверка ffmpeg, статус моделей и очереди. |

## Быстрый старт

Нужны **Python 3.10+** и ~3 ГБ свободного места (модели, демо-медиа, ffmpeg).

### Windows

Двойной клик по **`start.bat`** или в PowerShell:

```powershell
.\run.ps1
```

### Linux / macOS

```bash
chmod +x run.sh
./run.sh
```

Скрипт сам:

1. создаст `.venv` и установит зависимости;
2. скачает `ffmpeg`/`ffprobe` в `tools/ffmpeg` (если их нет в `PATH`);
3. скачает модели Whisper и эмбеддингов в `data/models`;
4. восстановит две демонстрационные лекции, если базы ещё нет;
5. запустит сервер на <http://127.0.0.1:8000> и откроет браузер.

Первый запуск занимает несколько минут из-за загрузки моделей (~1,2 ГБ).
Повторный — несколько секунд.

**Только посмотреть демо, без скачивания моделей:**

```powershell
.\run.ps1 -Fast          # Windows
./run.sh --fast          # Linux / macOS
```

В этом режиме работают демо-лекции (векторы уже посчитаны), но загрузка новых
видео недоступна, пока не выполнить `python scripts/download_models.py`.

Другие параметры: `-Port 8080`, `-NoBrowser`, `-Recreate` (пересоздать venv).

## Демо-лекции

В репозитории лежат две готовые лекции с медиа, превью, расшифровкой, главами
и векторами — их не нужно обрабатывать заново:

| Лекция | Длительность | Реплик | Глав |
|---|---|---|---|
| **Теорема Пифагора: от доказательства до практики** | 8:51 | 67 | 6 |
| **Как работают нейронные сети: от нейрона до обучения** | 7:57 | 64 | 6 |

Исходники демо: `demo/lectures.json` (текст, главы, base64-векторы),
`demo/media/*.mp4`, `demo/thumbnails/*.jpg`. Скрипт `scripts/seed_demo.py`
копирует их в `data/` и создаёт записи в БД без ASR, ffmpeg и интернета.

```bash
python scripts/seed_demo.py           # добавить отсутствующие
python scripts/seed_demo.py --force   # перезаписать демо-лекции
```

Полностью сбросить окружение: остановить сервер и удалить `data/vector.db`
(или весь `data/`, кроме `data/models`, чтобы не скачивать модели заново),
затем снова запустить `run.ps1` / `run.sh`.

## Как проверить за две минуты

1. Откройте <http://127.0.0.1:8000> — в библиотеке две лекции.
2. Нажмите на «Теорему Пифагора». Плеер и расшифровка синхронны: клик по
   реплике перематывает видео, активная реплика подсвечивается.
3. В поиске лекции введите **«как проверить прямой угол без транспортира»** —
   первый результат ведёт на 7:04, к рассказу о пифагоровых тройках.
4. Введите **«треугольник со сторонами три четыре пять»** — находится пример
   египетского треугольника на 5:02.
5. Переключите поиск на **«Все лекции»** и запросите **«как учится нейросеть»** —
   первый результат придёт из лекции про нейросети на 6:20, хотя слова
   «нейросеть» в этом фрагменте нет: «Так сеть постепенно уменьшает ошибку и
   учится на данных».
6. Задайте вопрос в блоке **«Спросить лекцию»**: «Почему теорема работает
   только для прямоугольных треугольников?» — ответ придёт с цитатами и
   таймкодами.
7. Скачайте конспект кнопкой **«Экспорт»** (Markdown) или субтитры VTT/SRT.
8. Загрузите свой MP4/WebM или вставьте ссылку YouTube/Vimeo — лекция пройдёт
   статусы «В очереди → Обработка → Готово» без ручных действий.

## Архитектура

```
┌──────────────────────────────────────────────────────────────────┐
│ Браузер: SPA без сборки (ES modules, History API)                 │
│  библиотека · плеер · расшифровка · поиск · Q&A · диагностика     │
└───────────────┬──────────────────────────────────────────────────┘
                │ fetch JSON / HTTP Range / VTT
┌───────────────▼──────────────────────────────────────────────────┐
│ FastAPI (app/main.py, app/api.py)                                │
│  безопасные заголовки · gzip · SPA fallback · стриминг видео      │
└───────┬───────────────────┬──────────────────────┬───────────────┘
        │                   │                      │
┌───────▼────────┐  ┌───────▼────────┐   ┌─────────▼─────────────┐
│ SQLite (WAL)   │  │ JobManager     │   │ SearchService         │
│ лекции, реплики│  │ ThreadPool(1)  │   │ dense + BM25 + MMR    │
│ главы, события │  │ прогресс в БД  │   │ кэш по версии индекса │
└────────────────┘  └───────┬────────┘   └─────────┬─────────────┘
                            │                      │
                ┌───────────▼──────────┐  ┌────────▼─────────────┐
                │ ffprobe / ffmpeg     │  │ model2vec            │
                │ аудио 16k mono, webp │  │ potion-multilingual  │
                └───────────┬──────────┘  └──────────────────────┘
                            │
                ┌───────────▼──────────┐   ┌──────────────────────┐
                │ faster-whisper       │   │ QA: retrieval +      │
                │ cues + слова + язык  │   │ extractive / LLM     │
                └───────────┬──────────┘   └──────────────────────┘
                            │
                ┌───────────▼──────────────────────────────────────┐
                │ TextRank-конспект · главы · термины · экспорт     │
                └──────────────────────────────────────────────────┘
```

**Путь обработки лекции**

1. Файл сохраняется в `data/media`, `ffprobe` определяет длительность и кодек.
2. `ffmpeg` извлекает аудио 16 кГц mono в `data/audio` и кадр-превью.
3. Whisper распознаёт речь и отдаёт cues + word-level timestamps; cues
   склеиваются в предложения по 2–14 секунд.
4. model2vec считает float32-векторы реплик, они лежат в SQLite.
5. TextRank строит конспект, алгоритм семантических сдвигов — главы, частотный
   анализ — термины.
6. Версия индекса увеличивается, кэш поиска пересобирается автоматически.

**Поиск** смешивает косинусную близость, BM25 по леммам, покрытие запроса
синонимами и фразовый бонус, затем MMR убирает почти одинаковые фрагменты.
Сниппеты подсвечивают совпадения с учётом лемм, а не только точных словоформ.

## API

Базовый префикс — `/api`. Интерактивная документация Swagger:
<http://127.0.0.1:8000/docs>.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/health` | Статус БД, ffmpeg, ASR, эмбеддингов, LLM, очереди. |
| `GET` | `/meta` | Версия, возможности, лимиты. |
| `GET` | `/stats` | Количество лекций, реплик, глав, часов, топ запросов, диск. |
| `GET` | `/lectures` | Список лекций. Параметры: `status`, `limit`. |
| `GET` | `/lectures/{id}` | Карточка лекции, конспект, главы, термины. |
| `PATCH` | `/lectures/{id}` | Переименовать / изменить описание. |
| `DELETE` | `/lectures/{id}` | Удалить лекцию, медиа и превью. |
| `POST` | `/lectures/upload` | Загрузка файла (`multipart/form-data`: `file`, `title`, `description`, `language`). |
| `POST` | `/lectures/import` | Импорт по ссылке: `{"url": "https://youtu.be/..."}`. |
| `POST` | `/lectures/{id}/reprocess` | Перезапустить обработку. |
| `GET` | `/lectures/{id}/transcript?words=true` | Реплики, опционально слова с таймкодами. |
| `GET` | `/lectures/{id}/subtitles.vtt` | Субтитры VTT (`.srt`, `?download=true`). |
| `GET` | `/lectures/{id}/media` | Видео с поддержкой HTTP Range (`HEAD` тоже поддерживается). |
| `GET` | `/lectures/{id}/thumbnail` | Превью кадра. |
| `GET` | `/lectures/{id}/export` | Markdown: конспект, тезисы, главы, расшифровка. |
| `GET` | `/search?q=...` | Поиск. Параметры: `lecture_id`, `limit` (1–50), `min_score`. |
| `GET` | `/search/suggest?q=...` | Подсказки запросов. |
| `POST` | `/lectures/{id}/ask` | Вопрос по лекции: `{"question": "...", "limit": 5}`. |
| `GET` | `/diagnostics/ffmpeg` | Версия ffmpeg. |

Примеры:

  -H "Content-Type: application/json" \

## Настройки

Все параметры читаются из переменных окружения (файл `.env` автоматически не
загружается). Шаблон — `.env.example`.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `VECTOR_DATA_DIR` | `./data` | Каталог данных. |
| `VECTOR_DB` | `data/vector.db` | Путь к SQLite. |
| `VECTOR_MODELS_DIR` | `data/models` | Каталог моделей. |
| `MAX_UPLOAD_MB` | `2048` | Лимит размера загрузки. |
| `MAX_DURATION_SEC` | `14400` | Лимит длительности. |
| `ASR_BACKEND` | `auto` | `auto` / `whisper` / `mock`. |
| `WHISPER_MODEL` | `small` | `tiny` / `base` / `small` / `medium` / `large-v3`. |
| `WHISPER_COMPUTE` | `int8` | Тип вычислений CTranslate2. |
| `WHISPER_LANGUAGE` | `auto` | Язык или автоопределение. |
| `ASR_CPU_THREADS` | CPU−2, 2–8 | Потоки распознавания. |
| `EMBEDDING_BACKEND` | `auto` | `auto` / `model2vec` / `hashing` / `openai`. |
| `OPENAI_API_KEY` | — | Ключ для OpenAI-эмбеддингов. |
| `LLM_ENABLED` | `0` | Включить LLM для конспекта и Q&A. |
| `LLM_BASE_URL` | — | OpenAI-совместимый endpoint (OpenAI, OpenRouter, Ollama). |
| `LLM_API_KEY` | — | Ключ LLM. |
| `LLM_MODEL` | `gpt-4o-mini` | Модель LLM. |
| `SEARCH_MIN_SCORE` | `0.16` | Минимальная релевантность. |
| `SEARCH_DEFAULT_LIMIT` | `12` | Результатов на страницу. |
| `FFMPEG_PATH` / `FFPROBE_PATH` | — | Явные пути к бинарникам. |
| `LOG_LEVEL` | `INFO` | Уровень логов. |

Пример подключения локального Ollama:

```bash
LLM_ENABLED=1
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen2.5:7b
```

Без LLM приложение полностью работоспособно: конспект и ответы строятся
экстрактивными алгоритмами с цитатами.

## Офлайн-режим и модели

| Компонент | Модель | Размер | Куда скачивается |
|---|---|---|---|
| ASR | `Systran/faster-whisper-small` | ~464 МБ | `data/models/whisper-small` |
| Эмбеддинги | `minishlab/potion-multilingual-128M` | ~751 МБ | `data/models/potion-multilingual-128M` |
| Медиа | ffmpeg + ffprobe (gyan.dev / johnvansickle) | ~200 МБ | `tools/ffmpeg/bin` |

```bash
python scripts/download_models.py                 # обе модели
python scripts/download_models.py --whisper base  # другой размер Whisper
python scripts/download_models.py --skip-embeddings
```

После загрузки интернет не нужен: распознавание, эмбеддинги, поиск, конспект,
главы, Q&A и плеер работают локально. Сеть требуется только для импорта по
ссылке, OpenAI-эмбеддингов или LLM — и то по желанию.

Если модель эмбеддингов отсутствует, включается детерминированный
hashing-эмбеддер: поиск остаётся рабочим, но качество семантики ниже. Статус
виден в `/api/health`.

## Тесты

```bash
python scripts/setup_tools.py   # ffmpeg нужен одному E2E-тесту
pip install -r requirements-dev.txt
python -m pytest -q
```

Ожидаемый результат: **156 passed, 1 skipped** (~10 секунд). Пропущенный тест —
дымовой прогон настоящего Whisper; он включается переменной:

```powershell
$env:VECTOR_SLOW_TESTS="1"; python -m pytest tests/test_asr.py -q
```

Покрытие: текст и лемматизация, нарезка cues, эмбеддинги и кэш, гибридный
поиск и сниппеты, Q&A с цитатами, все HTTP-методы, пайплайн с моками,
реальная загрузка файла до статуса `ready`, ASR-обёртка, VTT/SRT, экспорт.
Подробный отчёт — в [TESTS.md](TESTS.md).

## Ограничения

- **CPU-only по умолчанию.** На 8 ядрах 15-минутная лекция обрабатывается
  примерно за 9 минут. Для больших объёмов стоит включить GPU-сборку
  CTranslate2 или вынести ASR в отдельный воркер.
- **Одна очередь и один воркер.** Лекции обрабатываются последовательно;
  прогресс виден в UI. Это сознательный выбор для прототипа.
- **YouTube/Vimeo** могут требовать cookies или быть недоступны из вашей сети —
  ограничение `yt-dlp`, а не приложения.
- **Нет авторизации и мультипользовательского режима.** Прототип рассчитан на
  локальный запуск.
- **Качество ASR** зависит от записи: акценты, шум и термины могут
  распознаваться с ошибками. Конспект и главы — экстрактивные, без LLM они не
  переписывают текст.
- **Демо-лекции** синтезированы локально (TTS + слайды), чтобы репозиторий
  оставался портативным и без чужих видео.

## Решение проблем

<details>
<summary><b>Порт 8000 занят</b></summary>

Запустите на другом порту: `.\run.ps1 -Port 8080` или
`./run.sh --port 8080`. Либо найдите процесс:
`Get-NetTCPConnection -LocalPort 8000 | Select-Object OwningProcess`.
</details>

<details>
<summary><b>ffmpeg не найден</b></summary>

```bash
python scripts/setup_tools.py
```

Скрипт скачает сборку в `tools/ffmpeg/bin`. Если политика сети блокирует
загрузку, установите ffmpeg вручную и задайте `FFMPEG_PATH` и `FFPROBE_PATH`.
</details>

<details>
<summary><b>Модели не скачиваются</b></summary>

Проверьте доступ к Hugging Face. Можно запустить демо без моделей:
`.\run.ps1 -Fast`. Для загрузки новых лекций модели обязательны; повторный
запуск `python scripts/download_models.py` докачает недостающее.
</details>

<details>
<summary><b>Демо-лекции пропали или пути устарели</b></summary>

```bash
python scripts/seed_demo.py --force
python scripts/repair_paths.py   # если папка проекта переехала
```
</details>

<details>
<summary><b>Видео не перематывается</b></summary>

Проверьте, что сервер отдаёт `206 Partial Content`:
`curl -I -H "Range: bytes=0-1023" http://127.0.0.1:8000/api/lectures/demo-pythagoras/media`.
Если ответ `200`, медиафайл или прокси не поддерживают Range.
</details>

<details>
<summary><b>Долгая обработка</b></summary>

Следите за прогрессом в карточке лекции и в `/api/health` → `pipeline.active`.
Для ускорения уменьшите модель: `WHISPER_MODEL=base` или `tiny`, затем
перезапустите сервер и нажмите «Обработать заново».
</details>

<details>
<summary><b>Ошибка импорта PyAV на Python 3.14/3.15</b></summary>

`faster-whisper` тянет PyAV, у которого может не быть колеса под новую версию
Python. В `app/services/asr.py` есть shim: он подставляет заглушку, потому что
для распознавания из WAV PyAV не нужен. Ничего делать не требуется.
</details>
